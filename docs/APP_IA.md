# SumDiary App IA

## 1. 문서 정보

- 제품명: SumDiary
- 문서 목적: SumDiary의 앱 정보 구조, 주요 화면, 내비게이션, 사용자 과업 흐름을 정의한다.
- 작성일: 2026-06-04
- 상태: 초안
- 대상 플랫폼: Android, iOS

## 2. IA 원칙

- 일기 작성은 가장 빠른 진입점이어야 한다.
- 요약은 사용자의 기록을 되돌아보는 보조 흐름으로 둔다.
- 백업/보안/개인정보는 설정 안에 숨기되, 처음 켤 때는 충분히 설명한다.
- 온디바이스 AI와 외부 클라우드 백업은 사용자가 이해하고 직접 선택해야 한다.
- Android와 iOS는 같은 정보 구조를 유지하되 각 플랫폼의 네이티브 내비게이션 감각을 따른다.

## 3. 최상위 구조

```text
SumDiary
  - 일기
  - 요약
  - 설정
```

1차 출시에서는 3개 탭 구조를 기본으로 한다.

- 일기: 작성과 날짜별 기록 확인
- 요약: 오늘/이번 주 요약 확인
- 설정: 백업, 보안, 개인정보, 앱 정보

## 5. 주요 사용자 흐름

### 5.1 첫 실행

```text
앱 실행
  -> 앱 가이드
  -> 개인정보/민감정보 가능성 고지
  -> 온디바이스 AI 설명
  -> 일기 탭 진입
```

첫 실행에서 백업 연결을 강제하지 않는다.
앱을 이미 사용해 본 사용자를 위해 앱 가이드에는 작은 "건너뛰기" 액션을 제공한다.
개인정보/민감정보 가능성 고지와 필수 동의는 앱 가이드와 분리하며, 필요한 경우 건너뛸 수 없게 한다.

### 5.1.1 앱 가이드

앱 가이드는 3~4장으로 제한한다.

권장 구성:

1. 짧게 쓰는 일기
2. 기기 안에서 만드는 요약
3. Google Drive 암호화 백업
4. Face ID/Touch ID/Android 생체 인증 보호

가이드 규칙:

- "건너뛰기"는 우측 상단 또는 하단 보조 위치에 작게 배치한다.
- "시작하기"는 마지막 화면의 주 액션으로 제공한다.
- 이미 완료한 사용자는 다음 실행부터 가이드를 보지 않는다.
- 설정 > 앱 정보 또는 도움말에서 가이드를 다시 볼 수 있어야 한다.
- 가이드는 기능 소개용이며 법적 고지/동의 화면을 대체하지 않는다.

### 5.2 일기 작성

```text
일기 탭
  -> 작성 버튼
  -> 일기 입력
  -> 저장
  -> 오늘 일기 목록 갱신
  -> 백업이 켜져 있으면 백업 예약
```

### 5.3 요약 생성

```text
요약 탭
  -> 오늘 요약 또는 이번 주 요약
  -> 온디바이스 AI 지원 여부 확인
  -> 요약 생성
  -> 요약문과 감정 태그 표시
```

미지원 기기에서는 클라우드 AI fallback을 자동 실행하지 않는다.

### 5.4 백업 켜기

```text
설정
  -> 백업 설정
  -> 백업 설명
  -> Google Drive 연결
  -> 백업 비밀번호 생성
  -> Face ID/Touch ID/Android 생체 인증 사용 선택
  -> 첫 백업 실행
```

### 5.5 새 기기 복구

```text
설정 또는 첫 실행 복구 진입
  -> Google Drive 연결
  -> 백업 파일 찾기
  -> 백업 비밀번호 입력
  -> 복호화
  -> 병합/교체 선택
  -> 복구 완료
```

Face ID/Touch ID/Android 생체 인증은 새 기기 복구 수단을 대체하지 않는다.

### 5.6 데이터 삭제

```text
설정
  -> 개인정보 및 데이터
  -> 전체 로컬 데이터 삭제
  -> 백업 파일 삭제 여부 선택
  -> 확인
```

### 5.7 햅틱 피드백

햅틱은 의미 있는 결과를 확인시키는 용도로만 사용한다.

적용 지점:

- 일기 저장 성공
- 일기 삭제 확인
- 백업 완료
- 백업 실패
- 복구 완료
- 복구 실패
- Face ID/Touch ID/Android 생체 인증 성공/실패는 OS 기본 피드백을 우선한다.

비적용 지점:

- 탭 전환
- 일반 스크롤
- 일반 버튼 탭
- 텍스트 입력

설정:

- 햅틱은 기본 켜짐으로 제공한다.
- 사용자는 설정에서 햅틱을 끌 수 있어야 한다.
- OS 시스템 햅틱/접근성 설정을 존중한다.

## 6. 내비게이션 규칙

- 최상위 이동은 탭을 사용한다.
- 작성, 삭제 확인, 백업 설명은 modal 또는 bottom sheet 성격의 집중 화면으로 제공한다.
- 백업 복구와 데이터 삭제는 뒤로 가기 실수 방지를 위해 단계형 화면으로 제공한다.
- 위험 액션은 확인 화면을 둔다.
- 설정의 개인정보/백업/보안 화면은 깊이를 2단계 이하로 유지한다.

- 일기 작성 화면 방식: dialog, full screen, bottom sheet 중 선택
- 날짜 선택 방식
- 요약 미지원 기기 안내 문구

- Face ID/Touch ID/Android 생체 인증 사용 동의 UX
- 햅틱 피드백 on/off UX
- 백업 복구 병합/교체 UX
