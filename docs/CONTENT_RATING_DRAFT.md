# Store content rating draft

## Document status

- Status: release-candidate draft
- Basis: current SumDiary code, PRD, data map, privacy drafts, and store
  submission checklist
- Final gate: verify in Google Play Console and App Store Connect against the
  live questionnaire, final app binary, store listing, and legal review before
  submission.

Google Play requires a content rating questionnaire in Play Console. App Store
Connect generates the app age rating from the age rating questionnaire. This
document keeps the current draft answers auditable before the console forms are
submitted.

Official references:
- https://support.google.com/googleplay/android-developer/answer/9859655
- https://developer.apple.com/help/app-store-connect/manage-app-information/set-an-app-age-rating
- https://developer.apple.com/help/app-store-connect/reference/age-ratings/

## Product scope used for the draft

- SumDiary is a personal diary app for Android and iOS.
- The first release target country is South Korea.
- The app has no first-party account, social feed, public profile, public chat,
  marketplace, advertising, gambling, or user-to-user sharing feature.
- Diary content is created by the device owner and stored locally. If the user
  opts in to Google Drive backup, the backup payload is encrypted before upload.
- Diary text may contain sensitive personal information because users can write
  anything in a private journal. This is handled as a privacy and consent risk,
  not as app-provided mature media or public user-generated content.
- On-device summary providers process diary text locally. Unsupported devices
  must not fall back to cloud AI automatically.

## Google Play content rating draft

| Topic | Draft answer | Evidence and caveat |
| --- | --- | --- |
| App category | Productivity / lifestyle utility, not a game | SumDiary provides private diary, summary, backup, and lock flows. |
| Violence | No app-provided violent content | Users can type private diary text, but the app does not publish or recommend violent content. |
| Sexual content or nudity | No app-provided sexual content or nudity | Free-form private diary text can contain sensitive entries; no media feed or adult content feature exists. |
| Profanity or crude humor | No app-provided profanity or crude humor | User-authored private text is not shared or surfaced to other users. |
| Controlled substances | No app-provided controlled substance content | The app does not sell, promote, or instruct drug, alcohol, or tobacco use. |
| Gambling | No | The app has no betting, casino, lottery, sweepstakes, or simulated gambling feature. |
| User-generated content shared with others | No | Diary entries are private to the user and optional encrypted backup goes to the user's own Google Drive app data folder. |
| Location sharing | No | No foreground/background location permission or location-sharing feature is in scope. |
| Web access | No general web browser | Network access is limited to Google OAuth/Drive API when backup is enabled. |
| Ads | No | No ads SDK is included in the current release candidate. Reassess if monetization changes. |
| Target audience | General users, not designed for children | Privacy policy and PRD state that the app is not primarily directed to children. |

Expected Play rating must be generated by the Play Console questionnaire. Do not
claim a final rating until the live form is completed and saved.

## App Store age rating draft

| Topic | Draft answer | Evidence and caveat |
| --- | --- | --- |
| App category | Private diary / productivity utility | The app does not provide entertainment media, games, commerce, or social networking. |
| Mature or suggestive themes | None app-provided | Private user diary text can contain sensitive life events; the app does not provide mature content. |
| Violence, weapons, horror, or fear themes | None app-provided | No app-authored violent or horror content is included. |
| Sexual content or nudity | None app-provided | No media upload, public gallery, adult content, or dating feature exists. |
| Profanity or crude humor | None app-provided | User-authored private text is not a shared content feature. |
| Alcohol, tobacco, drug use, or references | None app-provided | No related instructional, promotional, or transactional feature exists. |
| Gambling or contests | No | No gambling, contest, loot box, or betting mechanic exists. |
| Medical or treatment information | No medical advice | Mood/emotion labels and summaries are diary aids, not diagnosis or treatment guidance. |
| User-generated content | Private only | Users create private diary text. There is no public UGC, moderation surface, or user-to-user sharing. |
| Web access | No unrestricted web access | Google OAuth/Drive is used for optional backup authorization and storage only. |
| Age assurance / minimum age | Not implemented in app | If the final store listing sets a minimum age, align it with App Store Connect settings and privacy/legal review. |

Expected App Store age rating must be generated by App Store Connect. Do not
claim a final rating until the live questionnaire is completed and saved.

## Pre-submission evidence checklist

- [ ] Google Play Console content rating questionnaire completed and screenshots saved.
- [ ] App Store Connect age rating questionnaire completed and screenshots saved.
- [ ] Final generated Google Play rating recorded.
- [ ] Final generated App Store age rating recorded.
- [ ] Store listing text and screenshots do not imply social, medical, child-directed, or adult-content features.
- [ ] Legal/privacy review confirms the app is not positioned as child-directed.
- [ ] Re-run this draft if ads, analytics, crash reporting, public sharing, media upload, location, web browsing, or cloud AI fallback is added.
