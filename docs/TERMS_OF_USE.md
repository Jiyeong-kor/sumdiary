# SumDiary 이용약관

## 문서 상태

- 상태: 출시 후보 초안
- 기준일: 2026-06-04
- 적용 대상: SumDiary Android 및 iOS 앱
- 출시 전 필요: 운영자 정보, 문의처, 배포 국가, 법률 전문가 검토

이 문서는 SumDiary 1차 출시 범위를 기준으로 한 이용약관 초안이다. 스토어 제출 전 실제 운영 주체와 법적 요구사항에 맞춰 검토해야 한다.

## 1. 서비스 개요

SumDiary는 사용자가 일기를 작성하고, 기기 안에서 요약하며, 사용자가 선택한 경우 암호화된 백업 파일을 외부 클라우드에 저장할 수 있도록 돕는 개인 일기 앱이다.

## 2. 계정

SumDiary 자체 회원가입과 자체 계정 서버는 1차 출시 범위에 포함하지 않는다. Google Drive 백업을 사용하는 경우 사용자는 Google 계정 권한 연결을 직접 승인해야 한다.

## 3. 사용자 데이터

- 사용자는 본인이 작성한 일기와 백업 비밀번호를 직접 관리할 책임이 있다.
- 백업 비밀번호를 잃어버리면 SumDiary는 암호화된 백업 파일을 복구할 수 없다.
- 사용자는 타인의 개인정보, 불법 자료, 권리를 침해하는 내용을 앱에 저장하지 않아야 한다.

## 4. 온디바이스 요약

SumDiary는 일기 원문을 외부 AI 서버로 전송하지 않는 온디바이스 요약을 목표로 한다. 기기 또는 OS 환경이 요약 엔진을 지원하지 않으면 요약 기능이 제한될 수 있다.

## 5. 백업과 복구

- 백업은 사용자가 직접 켠 경우에만 실행되어야 한다.
- 외부 클라우드 서비스 장애, OAuth 권한 만료, 네트워크 문제, 백업 비밀번호 분실로 인해 백업 또는 복구가 실패할 수 있다.
- 사용자는 중요한 데이터를 별도로 확인하고, 복구 가능성을 주기적으로 점검해야 한다.

## 6. 금지 행위

사용자는 다음 행위를 해서는 안 된다.

- 앱을 역공학해 보안 기능을 우회하는 행위
- 외부 클라우드 권한을 부정하게 사용하는 행위
- 악성 코드, 불법 자료, 타인의 권리를 침해하는 데이터를 저장하는 행위
- 앱의 정상적인 동작을 방해하는 행위

## 7. 서비스 변경과 중단

앱 기능은 보안, 안정성, 스토어 정책, 제3자 서비스 정책 변경에 따라 수정되거나 중단될 수 있다. Google Drive API 또는 OS 정책 변경은 백업 기능에 영향을 줄 수 있다.

## 8. 면책

SumDiary는 사용자가 입력한 일기 내용의 정확성, 백업 비밀번호 분실, 외부 클라우드 서비스 장애, 기기 분실 또는 사용자의 설정 오류로 인한 손해를 보장하지 않는다. 단, 관련 법령에서 허용하지 않는 면책은 적용하지 않는다.

## 9. 문의

출시 전 운영자 연락처와 문의 이메일을 확정해야 한다.

## 10. 출시 전 확정 필요 항목

- 운영자명
- 사업자 또는 개인 개발자 정보
- 문의 이메일
- 관할 법률과 분쟁 해결 절차
- 배포 국가별 필수 조항
